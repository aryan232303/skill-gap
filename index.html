Skill Gap Map

Paste the jobs you want and list what you already know. See which skills show up most, which ones you’re missing, and one small project to close each gap.

Separate with commas.

Prototype note: skills are matched against a built-in list of about 30 common engineering skills using keyword rules, so it runs without a server. The full product would use an LLM to read any posting, pull out skills in context (“must have” versus “nice to have”) and plan projects that fit your time.
